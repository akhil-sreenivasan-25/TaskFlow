# TaskFlow
TaskFlow is a Django-powered task management application designed to streamline personal and team productivity. It allows users to create, assign, track, and manage tasks efficiently with a clean and intuitive interface. 

 Features:
  - User authentication and role-based access
  - Task creation, editing, and deletion
  - Due dates, priority levels, and status tracking
  - Dashboard with task overview and filters
  - Email notifications and reminders
  - Responsive design for desktop and mobile

Tech Stack:
  - Backend: Django, PostgreSQL
  - Frontend: HTML, CSS, Bootstrap

run
  cd env1/taskflow
  pip install -r requirements.txt
  python manage.py migrate
  python manage.py runserver
